# FinTrack

FinTrack is a console-based Personal Finance and Spending Analytics System developed in C++.

The application allows users to record and manage income and expenses, monitor their budget, and generate basic financial analytics.

## Features

- Add, view, edit, and delete transactions
- Search transactions by category, description, or type
- Sort transactions by amount, category, or ID
- CSV-based data storage
- Automatic loading and saving of transaction data
- Income and expense tracking
- Spending analysis by category
- Budget tracking and alerts
- Savings rate calculation
- Identification of highest spending category
- Input validation

## Technologies

- C++17
- Object-Oriented Programming
- STL Vector
- STL Map
- STL Algorithms
- File Handling
- CSV Data Storage
